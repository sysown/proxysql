# Embedded TSDB Metrics Catalog

This document lists the metrics collected by the TSDB sampler and monitor threads.

## 1. Core Traffic Metrics
These metrics provide a high-level view of ProxySQL's throughput and performance.

| Metric Name | Type | Labels | Description |
| :--- | :--- | :--- | :--- |
| `proxysql_questions_total` | Counter | - | Total client questions (queries) received. |
| `proxysql_slow_queries_total` | Counter | - | Queries exceeding the slow query threshold. |
| `proxysql_active_transactions` | Gauge | - | Number of currently active transactions. |

## 2. Connection Pool Metrics
Crucial for understanding backend saturation and connection queuing.

| Metric Name | Type | Labels | Description |
| :--- | :--- | :--- | :--- |
| `proxysql_connection_pool_status` | Gauge | `hostgroup`, `endpoint`, `status` | Count of connections in specific states (Used, Free, OK). `status` can be 'Used', 'Free', 'Conn', 'Boot', 'Brok'. |
| `proxysql_connection_pool_latency_us` | Gauge | `hostgroup`, `endpoint` | Latency for connection pool operations. |

## 3. Query Digest (Top-K)
If `digest_mode='1'` is enabled, these metrics are recorded for the top `digest_topk` queries.

| Metric Name | Type | Labels | Description |
| :--- | :--- | :--- | :--- |
| `proxysql_query_digest_count` | Counter | `hostgroup`, `schema`, `user`, `digest` | Execution count for this specific query pattern. |
| `proxysql_query_digest_sum_time_us` | Counter | `hostgroup`, `schema`, `user`, `digest` | Total execution time in microseconds. |
| `proxysql_query_digest_rows_affected` | Counter | `hostgroup`, `schema`, `user`, `digest` | Total rows affected. |
| `proxysql_query_digest_rows_sent` | Counter | `hostgroup`, `schema`, `user`, `digest` | Total rows sent to client. |

*Note: The `digest` label contains the query hash (e.g., `0x123ABC...`). You can look up the full query text in `stats_mysql_query_digest`.*

## 4. Backend Monitoring (Active Probes)
Generated by the TSDB Monitor thread. These are distinct from the standard ProxySQL Monitor.

| Metric Name | Type | Labels | Description |
| :--- | :--- | :--- | :--- |
| `backend_probe_up` | Gauge | `hostgroup`, `endpoint` | 1.0 if the backend responded to the TCP probe, 0.0 otherwise. |
| `backend_probe_connect_ms` | Gauge | `hostgroup`, `endpoint` | Time taken to establish a TCP connection (ms). |

## 5. System Health
| Metric Name | Type | Labels | Description |
| :--- | :--- | :--- | :--- |
| `proxysql_uptime_seconds` | Counter | - | Process uptime. |
| `proxysql_memory_bytes` | Gauge | `type` | Memory usage breakdown (e.g., `type="stack"`, `type="sqlite"`). |
| `tsdb_series_count` | Gauge | - | Internal: Number of active time series being tracked. |
| `tsdb_disk_usage` | Gauge | - | Internal: Bytes used by the TSDB data directory. |
