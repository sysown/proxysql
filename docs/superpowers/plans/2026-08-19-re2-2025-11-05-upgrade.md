# RE2 2025-11-05 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade vendored RE2 to 2025-11-05 and vendor its required Abseil 20260107.0 dependency without adding system package dependencies.

**Architecture:** Build and install a private static Abseil prefix with CMake, then build the upstream RE2 Makefile against only that prefix through `PKG_CONFIG_PATH`. Centralize the RE2 plus static-Abseil link sequence in shared path variables and use it in every final binary so archive ordering is correct and unrelated source files do not include Abseil headers.

**Tech Stack:** C++17, RE2 2025-11-05, Abseil 20260107.0, CMake 3.16+, pkg-config, GNU Make, TAP C++ tests.

**Spec:** `docs/superpowers/specs/2026-08-19-re2-2025-11-05-upgrade-design.md`

## Global Constraints

- Vendor official RE2 **2025-11-05** and Abseil **20260107.0** source archives.
- Do not use a system RE2 or Abseil package at build or runtime.
- Retain the upstream RE2 Makefile build; do not require RE2 CMake 3.22.
- Build Abseil static libraries with CMake **3.16+**, tests disabled, and install rules enabled.
- Keep `query_processor_regex=2` behavior and the existing `RE2_PATH`/`obj/libre2.a` consumer layout.
- Do not reuse or upgrade the private Abseil tree inside clickhouse-cpp.
- Link `libre2.a` before all Abseil static archives in every final link command.
- Before every source build in a previously-used worktree run `PROXYSQL31=1 make cleanall`.

### Task 2: Vendor and build private Abseil, then upgrade RE2

**Files:**

**Interfaces:**

- Produces: `deps/abseil/abseil-cpp-20260107.0/install`, its `.pc` metadata, and `deps/re2/re2/obj/libre2.a` built against that prefix.

- [ ] **Step 1: Add the private Abseil build target**

  Add `abseil` before `re2` in the dependency target list and use this target shape:

  ```make
  ABSL_VERSION := 20260107.0
  ABSL_PATH := $(DEPS_PATH)/abseil/abseil-cpp-$(ABSL_VERSION)
  ABSL_INSTALL := $(ABSL_PATH)/install
  ABSL_STAMP := $(ABSL_INSTALL)/lib/pkgconfig/absl_base.pc

  $(ABSL_STAMP):
  	cd abseil && rm -rf abseil-cpp-*/ || true
  	cd abseil && tar -zxf abseil-cpp-$(ABSL_VERSION).tar.gz
  	cmake -S $(ABSL_PATH) -B $(ABSL_PATH)/build \
  		-DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=OFF \
  		-DABSL_BUILD_TESTING=OFF -DABSL_ENABLE_INSTALL=ON \
  		-DCMAKE_POSITION_INDEPENDENT_CODE=ON \
		-DCMAKE_INSTALL_LIBDIR=lib \
  		-DCMAKE_INSTALL_PREFIX=$(ABSL_INSTALL)
  	cmake --build $(ABSL_PATH)/build --parallel $(NPROCS)
  	cmake --install $(ABSL_PATH)/build

  abseil: $(ABSL_STAMP)
  ```

  Preserve `CC` and `CXX` by passing them to the CMake configure command.

- [ ] **Step 2: Replace the RE2 archive and build against only private pkg-config data**

  Extract `re2-2025-11-05.tar.gz` into the established `deps/re2/re2` directory. Make the target depend on `$(ABSL_STAMP)` and invoke its Makefile with a private package path:

  ```make

  	cd re2 && rm -rf re2-*/ || true
  	cd re2 && tar -zxf re2-2025-11-05.tar.gz
  	cd re2/re2 && PKG_CONFIG_PATH="$(ABSL_INSTALL)/lib/pkgconfig" \
		CC=${CC} CXX=${CXX} CXXFLAGS="-O3 -g $(STDCPP) -fPIC -DMEMORY_SANITIZER -DRE2_ON_VALGRIND" ${MAKE}
  ```

### Task 3: Centralize ordered RE2 and Abseil link flags

**Files:**

- Modify: `include/makefiles_paths.mk:39-41`
- Modify: `src/Makefile`, `lib/Makefile`, `test/Makefile`, `test/PrepStmt/Makefile`, `test/deps/cluster_simulator/Makefile`, `test/tap/tap/Makefile`, `test/tap/tests/Makefile`, `test/tap/tests/unit/Makefile`, `test/tap/tests_with_deps/deprecate_eof_support/Makefile`, and `plugins/genai/Makefile`

**Interfaces:**

- Consumes: the private Abseil `.pc` files produced by Task 2.

- [ ] **Step 1: Add shared path and link variables**

  Add the following alongside the existing RE2 paths in `include/makefiles_paths.mk`:

  ```make
  ABSL_VERSION := 20260107.0
  ABSL_PATH := $(DEPS_PATH)/abseil/abseil-cpp-$(ABSL_VERSION)
  ABSL_INSTALL := $(ABSL_PATH)/install
  ABSL_IDIR := $(ABSL_INSTALL)/include
  ABSL_LDIR := $(ABSL_INSTALL)/lib
  ABSL_PKG_CONFIG_PATH := $(ABSL_LDIR)/pkgconfig
  RE2_STATIC_LIB := $(RE2_LDIR)/libre2.a
  RE2_ABSL_LIBS = $(shell PKG_CONFIG_PATH=$(ABSL_PKG_CONFIG_PATH) pkg-config --static --libs absl_absl_check absl_absl_log absl_base absl_core_headers absl_fixed_array absl_flags absl_flat_hash_map absl_flat_hash_set absl_hash absl_inlined_vector absl_optional absl_span absl_str_format absl_strings absl_synchronization)
  RE2_STATIC_LIBS = -lre2 $(RE2_ABSL_LIBS)
  ```

  Use recursive `=` for both `RE2_ABSL_LIBS` and `RE2_STATIC_LIBS` so `pkg-config` runs after the Abseil dependency target exists. Keep `ABSL_IDIR` out of generic `IDIRS`; only `re2_vendor_unit-t` needs to compile an Abseil header directly.

- [ ] **Step 2: Replace every final-link `-lre2`**

  Replace each final-link occurrence of `-lre2` with `$(RE2_STATIC_LIBS)`. Where macOS lists `$(RE2_LDIR)/libre2.a` explicitly, append `$(RE2_ABSL_LIBS)` immediately afterward. Retain `-L$(RE2_LDIR)` for library lookup and add `-L$(ABSL_LDIR)` wherever `RE2_STATIC_LIBS` is consumed.

  Do not replace comments until their commands are changed; afterwards run:

  ```bash
  rg -n --glob='Makefile' --glob='*.mk' -- '-lre2|libre2\.a'
  ```

  Every live final link must show the ordered `RE2_STATIC_LIBS` or `RE2_STATIC_LIB` followed by `RE2_ABSL_LIBS` form. The `deps/Makefile` target prerequisite is the only permitted raw `obj/libre2.a` reference.
