# PR 6156 Fast-Forward Handoff Safety Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the query-rule permanent fast-forward handoff release all ProxySQL-owned query state, never retain a packet-backed processlist pointer, and never consume converted COM_FIELD_LIST requests.

**Architecture:** Extend the existing focused TAP first so ordinary COM_QUERY and converted COM_FIELD_LIST expose the reviewed bugs. Add one session helper that finalizes parser/query-processor state without invoking response-completion behavior, call it before packet ownership moves to fast-forward, and gate the action on `com_field_list == false`.

**Tech Stack:** C++17, ProxySQL MySQL session/query processor, MySQL C API, TAP, GNU Make, isolated TAP infrastructure.

- [ ] **Step 2: Implement cleanup without response-completion side effects**

Add immediately before `GPFC_QueryRule_SwitchToFastForward()`:

```cpp
void MySQL_Session::GPFC_QueryRule_FinalizeFastForwardHandoff() {
	CurrentQuery.set_end_time(thread->curtime);
	CurrentQuery.end();
	CurrentQuery.MyComQueryCmd = MYSQL_COM_QUERY___NONE;
	CurrentQuery.QueryPointer = nullptr;
	CurrentQuery.QueryLength = 0;
	GloMyQPro->delete_QP_out(qpo);
	current_query_user_variable_safe = false;
	current_query_user_variable_unsafe_fallback = false;
	current_query_user_variable_context_change = false;
	pending_user_variable_set.reset();
}
```

This intentionally does not call `RequestEnd()`: no backend response has been received, and the fast-forward transition owns subsequent state-machine changes.

- [ ] **Step 3: Finalize state before either packet ownership path**

After successful reconstruction and before the conditional free/replace block, call the helper unconditionally:

```cpp
	GPFC_QueryRule_FinalizeFastForwardHandoff();
	if (reconstructed.ptr != pkt.ptr) {
		l_free(pkt.size, pkt.ptr);
		pkt = reconstructed;
	}
```

Remove the old conditional `QueryPointer` and `QueryLength` assignments because the helper now covers both ordinary and reconstructed packets.
